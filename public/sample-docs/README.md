## 🚀 วิธีนำไปทดสอบบน UniWorkload AI

1. เปิดเบราว์เซอร์ไปที่ **http://localhost:5173**
2. ไปที่แท็บ **"นำเข้าคำสั่ง & AI Parser"**
3. ลากไฟล์ PDF จากโฟลเดอร์ `sample-documents/` ไปวางในกล่องอัปโหลด (Drag & Drop) ได้ทันที
4. ดูการทำงานของระบบ:
   - หากเป็น **Digital PDF** (เช่น `nrru_order_coop.pdf`, `mcu_order_exam_committee_2567.pdf`): ดึงข้อความได้ทันทีใน 0.1 วินาที
   - หากเป็น **Scanned Image PDF** (เช่น `nsru_order_257_2569_construction.pdf`, `cmu_order_building_renovation.pdf`): ระบบจะ Render หน้าแรกเป็นภาพและส่งเข้า Tesseract OCR Neural Network ภาษาไทย (`tha+eng`) อัตโนมัติ!
