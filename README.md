## 🚀 4 โมดูลหลักที่นำเสนอใน Prototype

### 1. ระบบนำเข้าและสกัดข้อมูลคำสั่งอัจฉริยะ (Multi-Channel Ingestion & AI OCR Parser)
- รองรับไฟล์เอกสารคำสั่งทางราชการทั้ง **PDF**, **รูปถ่ายจากกล้องมือถือ**, และ **ภาพแคปหน้าจอแชตกลุ่ม LINE**
- มีระบบจำลองการสกัดข้อความภาษาไทยและแปลงเลขไทยเป็นเลขอารบิกอัตโนมัติ พร้อมค่าความแม่นยำ (Confidence Score 98.4%)
- **Quick Verification Drawer**: หน้าต่างตรวจทานข้อมูลด่วน (5–10 วินาที) ก่อนกดยืนยันบันทึกเข้าระบบ
- ปุ่มทดลอง **"โหลดตัวอย่างคำสั่งจริง (มรภ.นว. 1299/2569)"** เพื่อสาธิตให้อาจารย์ที่ปรึกษาชมได้ทันที

### 2. ระบบกระจายและลิ้นชักหลักฐานส่วนบุคคล (Smart Dispatch & Personal Drawer)
- กระจายภาระงานเข้าสู่บัญชีอาจารย์แต่ละท่านอัตโนมัติ โดยอิงจากรายชื่อและบทบาทในคำสั่ง (เช่น ประธาน, กรรมการ, เลขานุการ)
- ระบบจัดหมวดหมู่แฟ้ม: รอดำเนินการ, ปฏิบัติงานแล้วเสร็จ, และแฟ้มรวบรวมหลักฐาน
- หน้าต่าง **"แนบหลักฐานปฏิบัติงานจริง"** รองรับการอัปโหลดภาพถ่ายหน้างาน, ใบลงทะเบียน, หรือเกียรติบัตร

### 3. ระบบปฏิทินงานแบบผสม 2 ทาง (Smart Dual Calendar)
- **Web Calendar**: ปฏิทินแบบ Interactive บนหน้าเว็บ สลับมุมมองรายเดือน (Month Grid) และวาระงาน (Agenda List) ได้ พร้อมปุ่ม *"กดยืนยันว่าปฏิบัติงานแล้ว (Mark as Done)"*
- **iCalendar Feed Sync (RFC 5545)**: ให้ URL ลิงก์เฉพาะบุคคลสำหรับนำไป Subscribe ใน Google Calendar / Apple Calendar บนสมาร์ตโฟนได้โดยตรง โดยไม่ต้องผ่านการล็อกอินที่ยุ่งยาก พร้อมปุ่มดาวน์โหลดไฟล์ `.ics` จริงที่เปิดได้ทันที

### 4. ผู้ช่วยจัดเตรียมข้อมูล e-Portfolio (e-Portfolio Copilot)
- ถอดรหัสโครงสร้างตามฟอร์มจริงของระบบประเมินผลการปฏิบัติราชการ มรภ.นครสวรรค์ (เมนู **แฟ้มภาระงานอื่น ๆ**) ครบทั้ง 5 ช่อง:
  1. **ปีการประเมิน**: ระบบดึง พ.ศ. ให้เองอัตโนมัติ
  2. **รอบการประเมินที่**: คำนวณรอบ 1 (1 ต.ค. - 31 มี.ค.) หรือ รอบ 2 (1 เม.ย. - 30 ก.ย.) ให้อัตโนมัติ
  3. **หัวข้อภาระงาน**: สกัดชื่อกิจกรรมและบทบาทอย่างกระชับ
  4. **อ้างอิงภาระงาน**: จับคู่กับหมวดภาระงานของมหาวิทยาลัย
  5. **แนบเอกสารหลักฐาน**: รวมไฟล์คำสั่งและภาพถ่ายหน้างาน
- ปุ่ม **1-Click Copy** แยกตามช่อง และปุ่ม **"1-Click Copy ข้อมูลทั้งหมด"** ที่พร้อมนำไปวางในระบบ e-Portfolio ได้ทันที
